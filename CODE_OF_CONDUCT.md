# Code of Conduct

## Purpose

This project welcomes contributors with different experience levels. Participation should be constructive, respectful, and focused on improving the code and documentation.

## Expected behavior

- Use respectful language.
- Explain technical disagreements with evidence.
- Accept feedback without personal attacks.
- Help beginners understand the issue rather than dismissing questions.
- Respect privacy and avoid publishing personal information.
- Credit the original authors of third-party code and assets.
- Keep discussions focused on the project.

## Unacceptable behavior

- Harassment, threats, intimidation, or discrimination.
- Personal insults or repeated disruptive behavior.
- Publishing private information without permission.
- Deliberately misrepresenting another contributor's work.
- Removing required third-party copyright or license notices.
- Sharing credentials, private PINs, signing keys, or confidential logs.

## Maintainer responsibilities

Maintainers may edit or remove content that violates this policy, close disruptive discussions, or restrict participation when necessary. Decisions should be proportionate to the behavior and applied consistently.

## Reporting

Report conduct concerns privately to the repository maintainers through an available private contact or GitHub reporting mechanism. Do not include sensitive personal data in a public issue.

## Scope

This policy applies to repository issues, pull requests, code reviews, discussions, and other project spaces where a participant represents the project.
